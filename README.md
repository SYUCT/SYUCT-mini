## 本地运行

1. 安装微信开发者工具。
2. 直接导入本目录。
3. 测试时可使用项目中的 AppID，或在开发者工具中切换为测试号。
4. 点击“编译”后检查首页、资料搜索和至少一份 20 页以上的本地 PDF 预览。

本项目运行时不主动请求远程文档：地图、相册和 13 份 PDF 图片预览均在代码包中；高清图片通过分包按需加载。其余 PDF、Word、Excel 会在用户确认后复制 `www.syuct.top` 链接，由用户在浏览器中查看。

## 更新资料

### 同步网页版内容

1. 先确认网页版 `README.md` 中的当前版本和更新日期。
2. 首页、栏目标题、说明、提醒和链接统一修改 `data/content.js`。
3. 文档标题、分类、说明、搜索词和栏目分组统一修改 `data/documents.js`。
4. 同步后更新 `SITE.sourceVersion`、`SITE.sourceRevision` 与 `SITE.updatedAt`。
5. 执行 `python3 scripts/verify-sync.py`，确保五项常问、栏目分组和资料说明没有漂移。

### 修改标题、分类或搜索关键词

只改 `data/documents.js` 中对应文档对象或 `DOC_DESCRIPTIONS`。各栏目页面与资料中心会自动复用同一份信息。

### 调整某栏目展示顺序

修改 `data/documents.js` 中的 `SECTION_GROUPS`，只填写文档 ID，不要复制标题和文件路径。

### 新增本地 PDF 图片预览

1. 将逐页 JPG 放到某个 `packages/preview-x/<document-id>/` 目录。
2. 更新 `scripts/gen-manifest.py` 的 `RANGE_MAP`。
3. 执行：

```bash
python3 scripts/gen-manifest.py
python3 scripts/copy-preview-pages.py
python3 scripts/verify-previews.py
```

预览页使用单页 `swiper`，只加载当前页前后各两页。单个分包必须小于 2 MiB；校验脚本会在超过 1.85 MiB 时预警。
